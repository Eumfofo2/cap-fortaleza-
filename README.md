# FortClinic 🏢 (projeto)
## Objetivo √
- promover uma plataforma cuja funcao é ajudar a consultas em diversas areas que trabalham principalmente pela forma online
- 1. **ajuda ao cliente**: quem busca uma fonte de __ajuda/consulta__ de forma online para no final marcar com algum(a) profissional de tal area presencial ou online, vem desse ponto, alem de oferecer liberdade de pesquisas e filtros, procura por categoria e profissão, busca por topicos e outros
  2. **profissional/organização**: quem ou alguma organização esta em busca de tebtta levantar mais margen de pessoas e marketing para sua profissão, esse ponto e importante, alem de dar uma lista de ferramentas para ela utilizar como lista de consultas __pre-marcadas__, __faixa de atendimento/monetização__, dashboard geral, e outros

## Estrutura √
```
- front end
- back end
- banco de dados
- segurança ao momento de comunicação front x back
- devops/produção (por github)
```
